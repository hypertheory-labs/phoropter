# Seed: `phoropter affected`, what's left

Chambray built it: `affected <file>…` and `--since <ref>`, printed as a lens. What's
left:

- **The same answer as a page,** so the TUI can ask it of the place you're looking at
  (Jeff, 2026-11-20). The TUI reads only served pages, so it's the dev server's, and a
  profile addition.
- **Blame with reasons:** which plan's work last changed a line, through the `Plan:`
  trailers (`shelf/trailers.md`), not anchors.
- **Drift as a report:** `affected README.md` lists entries whose quotes aren't found
  any more, which is most of the documentation seed's check.
- **What came after a plan** (Jeff and Claude, 2026-11-21): "what was the blast radius
  of that last plan, anything we should look into?" For one plan, the facts phoropter
  has or nearly has: later entries anchored where its entries are (each place page
  lists them; nothing gathers them across one plan yet), commits since its as-built
  head that changed its anchored lines, with subjects and `Plan:` trailers (madras's
  `removedBy`, widened from the commit that removed a quote to every commit that
  touched the span), and its guesses beside them, open ones first. Guesses rarely have
  anchors, so they're reached through their plan's other entries. **The output is a
  lens** (Jeff: "I freaking LOVE"), so either of us can add notes to it, and whether a
  guess held stays the reader's call. `affected` on a plan file today asks what's
  anchored *in* it, a different question; the flag or page this gets is open
  (`--after plans/x.md` was one thought). Later is better: we're still learning what
  the questions are.

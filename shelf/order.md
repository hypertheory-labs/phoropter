# The shelf, in the order to work through it

Claude keeps this, and reorders it when a seed is added, picked up, or moves. Jeff asked
for it: the files sort alphabetically, and an order is a help to a person reading the
shelf. The seeds keep their names, because landed plans cite them by name.

1. **`trial.md`:** the goal. A fresh repository, `phoropter init`, a fresh agent, on
   Jeff's Windows VM. Nothing known stands in its way since chiffon.

   *Then the trial. What it finds reorders everything below.*

2. **`indexing.md`:** the TypeScript indexer installed without a clone (npm), and
   containers. The trial says whether a clone hurts. Go installs since tulle.
3. **`one-server.md`:** the server question, a revisit of batik's port decision. The
   trial says how much the extra terminal hurts.
4. **`recipes.md`:** "give me a brief", and noticing a missing ambient plan. The trial's
   first sessions will show which recipes an agent misses.
5. **`pages.md`:** the repository is public now, and Jeff has a demo coming. Cheap to
   check alongside `one-server.md` (both serve a site under `/<repo>/`).
6. **`exceptions.md`:** an exception to an earlier plan, as distinct from overriding it.
   A format change.
7. **`draft-places.md`:** one page listing every entry, so "has anyone turned this
   down?" is one fetch.
8. **`file-pages.md`:** file pages, and the TUI reading mode that may replace an LSP.
   Needs `paths.md` first.
9. **`paths.md`:** `›` paths resolving to line ranges. Three gaps in the TUI's ledger.
10. **`select-choices.md`:** a Select's chosen options as properties. One gap in the
    ledger. Small.
11. **`lenses.md`:** what's still open about lenses. Waits for Jeff to want one of them.
12. **`approaches.md`:** the class's approach files, and a catalog. Jeff builds the
    catalog for the class first.
13. **`re-check.md`:** reasons that expire, and `**Holds while:**`. A format change.
14. **`ui-plugins.md`:** other UIs as plugins, and a short name.
15. **`plan-name-links.md`:** a plan's name in prose links to the plan. "Way future."
16. **`contributing.md`:** an issue that carries a plan. Once someone else contributes.

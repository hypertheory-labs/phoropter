## Chose: A served site is built into the cache, not the repository
- where: `src/cli.ts`
- quote: `// serve: the site goes in the cache, never into the repository.`

**Because (Claude, not asked):** `serve.ts` built into `site/` beside wherever it ran,
which in this repository is gitignored. Run in any repository, that's a write into it.
`phoropter build` still writes `site/` by default, because building a site is what you
asked for.

## Chose: Committed indexes are read from the working tree
- where: `src/store.ts`
- quote: `committedPath(sha: string, pkg: string): string {`

**Because (Claude, not asked):** an index is the same fact wherever it's read from, so
the store doesn't care whether `.phoropter/index/` is committed yet. That's what lets a
build use what `phoropter index` just wrote, before it's committed.

## Chose: Tests get a temporary cache
- where: `test/cache.ts`
- quote: `process.env.XDG_CACHE_HOME = mkdtempSync(join(tmpdir(), 'phoropter-cache-'));`

**Because (Claude, not asked):** every build writes the cache now, and a test run
shouldn't fill a real `~/.cache`. Each test file that builds imports this first.

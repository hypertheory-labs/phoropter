# As built: organdy

Built in one evening, Halloween, as Jeff's bookend before a week away. The order kept the
plan whole: golden sites from the Node version first, then the Go core, the command,
the tests, and only then the deletion of `src/`. The Go version matched every golden
page on the first comparison that had the indexers and repository name right:
mock-control's 16 pages, phoropter's 85, and the dev server's draft, notes and plan
pages. Microdata, `rel` links, paths and slugs were all identical, with **no prose
differences at all**. Claude's estimates were goldmark 0.9, structure 0.8, and landing
whole 0.75. Structure needed no fixes.

## Changed: Plan structure is read by a line scanner; goldmark renders prose only
- where: `internal/site/plan.go`
- quote: `// The structure is found by a line scanner that knows the format's few`

**Because (Claude, measured):** the plan had goldmark's tree carry plan structure. But
`src/plan.ts` only used `marked` to cut the source into blocks and keep each block's raw
text. The format's blocks are few: ATX headings and lists, outside code fences. A small
scanner gives the same raw slices exactly, and nothing about a markdown library's tree
can move them. Goldmark renders every reason, intro and comment, and prose came out the
same anyway.

## Changed: First-party indexers are found from the binary's own repository
- where: `internal/site/indexers.go`
- quote: `func firstPartyDir() string {`

**Because (Claude, measured):** Node found `indexers/` beside its own source. A Go binary
has no source beside it, so it walks up from where it is, through symlinks, to a
directory holding `indexers/README.md`. `PHOROPTER_INDEXERS` overrides that, and the
tests use it. A binary built in a clone finds them. One installed elsewhere doesn't, and
gets indexers from `PATH` only (see the second guess).

## Chose: Inline markdown is parsed with only goldmark's paragraph parser
- where: `internal/site/render.go`
- quote: `// inlineMD parses with only the paragraph block parser, so a title like`

**Because (Claude, not asked):** `marked.parseInline` never makes blocks. Full goldmark
would make a title like "1. Install" into a list, or a title starting with `#` into a
heading.

## Chose: `.gitignore`'s `site/` is anchored to the root
- where: `.gitignore`
- quote: `/site/`

**Because (Claude, measured):** unanchored, it ignored `internal/site/` too, and git
refused the core's first commit.

## Chose: Go symbols are named for the module path now
- where: `go.mod`
- quote: `module github.com/hypertheory-labs/phoropter`

**Because (Claude, not asked):** one module means one module path, and scip-go names a Go
symbol's package by it, so `phoropter-tui` became `github.com/hypertheory-labs/phoropter`.
No landed plan anchors a Go symbol, so nothing broke. A later one uses the new name, as
`phoropter symbols` prints it.

## Chose: Jeff's `phoropter` is the Go binary
- where: `CLAUDE.md`
- quote: `` `bin/phoropter`. A binary built in this repository finds `indexers/` by walking up ``

**Because (Claude, not asked):** the symlink pointed at `src/cli.ts`, which is gone.
`~/.local/bin/phoropter` now points at `bin/phoropter`, built here.

## Answered: The Go version builds every golden site with identical structure
**Answer (Claude, measured):** held. Mock-control (16 pages), phoropter (85) and the
three served pages match in every microdata property, `rel`, path and slug, with no
prose differences. `go test ./...` keeps checking it.

## Answered: A Go repository needs nothing installed but the binary and scip-go
**Answer (Claude, measured):** partly disproved. With no Node on `PATH`, the binary built in
a clone serves, lists Go symbols and resolves them, and the TUI opens. But a binary
outside the repository, as `go install` leaves it, finds no first-party indexers.
`phoropter symbols` on a Go file says no indexer handles `.go` files, and Go symbol
anchors would show `no-index`. The Go indexer can't be installed onto `PATH` yet either:
its module isn't `go install`-able by name. The shipping plan has to make first-party
indexers installable (`phoropter-index-go`, `phoropter-index-typescript`), or build the Go
one into the binary. It's on the shelf, in `shelf/indexing.md`.

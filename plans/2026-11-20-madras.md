# When a quote is gone, `affected` says where it was last found and what removed it

Chambray's `affected` marks an anchor whose quote isn't found now with "though its
quote isn't found there now". On `README.md` that was four entries, and reading them
back with `git log -S`, three of the four quotes were removed by the plan's own work,
which anchored the text it was about to replace, as the guide says to. The fourth was
removed by a later plan. The note said the same thing about all four, so it read as
four cases of drift.

The first fix proposed was a note saying "replaced by its own work", and Jeff's
guardrail caught it: that's phoropter claiming a cause. What phoropter knows is
commits. The reader, a person or an agent at the point of contact, draws the meaning,
and may draw one nobody here thought of, unless the output has already told them what
it means.

## Decision: The note gives the last commit the quote was found at, and the commit that removed it
- where: `internal/site/affected.go`
- quote: ``return fmt.Sprintf("- %s — %s, at `%s`, though its quote isn't found there now", wrapSpan(h.Doc.File+" › "+h.Entry.Title), strings.ToLower(h.Entry.Kind), where)``

**Because (Jeff, then Claude):** the last commit found is the latest of the anchor's
own views where it matched: the as-built head, or the base. The removing commit is the
newest one git's pickaxe (`git log -S`) finds changing the quote's count in that file
between there and the commit read at, with its subject, and the plan its `Plan:`
trailer names when it has one. When the pickaxe finds nothing, say because the quote
spans lines the file has since reflowed, the note says only where it was last found.

## Decision: No word in the output says what it means
- where: `internal/site/affected.go`
- quote: `func LensLine(h Hit) string {`

**Because (Jeff):** drift, own work, reconciled: each is a reading, and a reading
printed by the tool is taken at face value and closes off other ones. The note is
commits and subjects, and every entry stays listed, so the lens is the record and the
reader does the interpreting.

## Decline: Hiding entries whose quote their own work removed
**Because (Claude, then Jeff):** deciding which removals don't count is the
interpretation this plan takes out. The note gives what's needed to see it.

## Guess: Reading the notes, a person can tell a plan's own work from a later change without running git
**Disproved if:** on `affected README.md`, Jeff or an agent still has to run `git log`
to say which of the four quotes were removed by their own plan.

## Changed: `symbols` also prints an indexer's needs itself
- where: `main.go`
- quote: `// An indexer that says what it needs won't run without it; say so here,`

**Because (Claude, not asked):** the same loop one step later. An indexer that's found
but reports `needs`, such as a clone without `npm install`, would fail in `symbols`, and
the failure sent you to `doctor`, which reports needs only for schemes the plans already
anchor. Now `symbols` prints each need and its install line before running anything. A
test holds it, with a fake indexer that needs something.

## Chose: `doctor` and `symbols` share one fix line
- where: `doctor.go`
- quote: `func (d doctorFacts) missingFix(s string) string {`

**Because (Claude, not asked):** two commands giving their own advice for the same gap
is how they'd drift into disagreeing. `firstPartySchemes` now knows each indexer's file
extensions and what it calls a package, so `symbols` can pick the scheme from a file
and say the same thing `doctor` would.

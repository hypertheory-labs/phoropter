# A home link in every header

A human accommodation. Getting back to the home page means finding the nav line under
the header, which differs by page, or editing the URL. The header's links are in the
same place on every page.

## Decision: Every header's links start with "home"
- where: `src/render.ts`
- quote: ``<span class="links"><a rel="help" href="${rel(here, 'guide/')}">guide</a>``

**Because (Jeff):** a person wants one place to go home from, wherever they are. It's
first, so the links read home, guide, profile; the dev server's draft link comes after
home, so it reads home, draft, guide, profile.

## Decision: The draft link goes after home
- where: `src/serve.ts`
- quote: `html.replace('<span class="links">'`

**Because (Claude, not asked):** the server inserts it at the start of the links today,
which would put it before home.

## Decline: A rel on the home link
**Because (Claude, not asked):** there's no registered relation that means "the site's
root" in current HTML (`start` and `index` were dropped), and an agent already gets
there: plan and place pages link the home page with `rel="collection"`, and the profile
says so. The link is for people.

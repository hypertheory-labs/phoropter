# As built: muslin

Built as planned, with no departures, in three commits that each read alone: the
template (`init.md`), the command, and the README. Jeff read the template before the
command was written, and his notes went into it: keep the default when in doubt, and
plan whenever you'd want a second opinion or a change would alter an earlier plan.
`go test -count=1 ./...` passes. In a fresh repository, `phoropter init` writes the
draft, prints the walkthrough, refuses a second time, and the draft renders on the dev
server with every entry and prompt.

One finding, from a question Jeff asked while reading: Claude Code's plan mode. Its
read-only boundary is the strongest form of "wondering isn't asking", because the
harness enforces it and the person chooses it. But it ends by asking for approval, and
its plan lives in the session, not in the repository. That's a gate, and plans here
aren't one. The template takes no position on agent tooling. Jeff: it's open
configuration, and "any sense that we are going to make *all the decisions* for you here
is doomed to fail." Phoropter can't keep an agent from changing a repository anyway.

Jeff's notes on the template that weren't for this plan went to seeds:
`shelf/recipes.md` ("give me a brief", noticing a missing ambient plan) and
`shelf/ui-plugins.md` (`phoropter ui` starts the server when there's none, for the
server and TUI friction cart).

## Chose: A new source, `phoropter's default`
- where: `init.md`
- quote: `**Because (phoropter's default):** the code shows what was done, and the plan shows why,`

**Because (Claude, not asked; Jeff read it):** nobody in a new repository chose these
conventions. They came with the tool, and the guide's sources (a person, `measured`, an
agent) would each claim something untrue. It's a source written in prose, as the guide
allows, not a format change. An answered prompt's reason takes the person's name when it
converts.

## Chose: The template's `drafts/` fallback has the agent edit `.gitignore` at conversion
- where: `init.md`
- quote: ``**If unanswered:** no. When this plan converts, the agent adds `drafts/` to``

**Because (Claude, not asked):** a repository that keeps `drafts/` out of main needs the
line in `.gitignore`, and the conversion commit is where the decision lands. `init` itself
still writes only the draft.

## Chose: The walkthrough says when a repository already has plans
- where: `init.go`
- quote: `fmt.Fprintf(&b, "\nThis repository already has %s. The draft sits beside them as the\n"+`

**Because (Claude, not asked):** the plan didn't say what `init` does where plans exist.
Refusing would be wrong, since a repository like this one has plans and no "How we work
here". So it writes the draft and says it sits beside them.

## Chose: The pointer names the first plan by its title
- where: `init.go`
- quote: `` const pointer = `## Plans (phoropter) ``

**Because (Claude, not asked):** the first plan's filename has a date and a meaningless
word, neither of which `init` can know ahead of time. Its title and "the oldest in
`plans/`" find it without anything that changes.

## Chose: A test keeps the README's pointer the same as the one `init` prints
- where: `main_test.go`
- quote: `func TestREADMEShowsThePointerInitPrints(t *testing.T) {`

**Because (Claude, not asked):** the README shows the pointer, so there are two copies,
and two copies that can disagree are what this plan set out to end. The test fails the
build if they drift.

## Chose: `init` in a repository with no commits says so, as the rest of phoropter does
- where: `main.go`
- quote: `fail(root + " has no commits yet; phoropter reads a repository at a commit")`

**Because (Claude, not asked):** `base:` needs a commit. `init` runs after the existing
check, so a brand-new repository hears the same thing `phoropter` already tells it.

converted with every prompt dropped and each fallback folded into its reason and labeled,
built to a site with all 12 Decisions and 2 Guesses and nothing unresolved. Whether it
reads as testimony rather than instructions is a reader's judgment, and that reader is
Jeff, not the agent that wrote it.

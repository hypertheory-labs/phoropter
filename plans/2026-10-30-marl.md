# What an agent can read without reading prose: source, date, and the plan's own work

Sorrel made plans link to each other. A reader arriving cold still has to read prose
to learn three things that matter most for trusting an entry: where its reason came
from, how old it is, and whether a quote that's gone was removed by the plan itself or
by something later. This plan puts each of those in the page's structure. It also
binds the dev server to localhost, which rides along because it's one line.

This plan was put up as a draft in its cart first, and Jeff said "go" without
annotating it. Verdicts on answered guesses are left to their own plan. That's a revisit of quince,
which declined them, and per bodkin a revisit doesn't go inside another plan.

## Decision: A reason's source is `itemprop="source"`, exactly as written
- where: `src/render.ts`
- quote: ``${entry.body ? `<div class="reason" itemprop="reason">${block(entry.body)}</div>` : ''}``

**Because (Jeff and Claude):** the source is the strongest trust signal an entry has,
and today it exists only as bold prose. It's the parenthesis in `**Because (…):**` or
`**Answer (…):**`, kept word for word. No categories, and nothing in the code knows any
source's name; finding every "Claude, not asked" entry is a substring match. An entry
without one (a `Guess:`, whose lead is `Disproved if`) has no source.

## Decision: Plans carry their date, and are ordered by the commit that added them
- where: `src/site.ts`
- quote: ``const name = basename(file, '.md').replace(/^\d{4}-\d{2}-\d{2}-/, '');``

**Because (Jeff and Claude):** archaeology is mostly about order, and the date exists
only in the filename. The filename's date becomes `itemprop="date"`. It can't be the
order by itself, because vellum, ferrule, and tallow share 2026-10-30. The commit that
added each plan (13:23, 13:44, 13:52) is what orders them, and it's shown beside the
date.

**Which way the lists run (Claude, unanswered, so its fallback):** the home page runs
oldest first, because it reads as a history. Reverse pages run newest first, because
someone arriving at a file usually wants what touched it last.

## Decision: A plan's anchors are also shown at its as-built's head
- where: `src/site.ts`
- quote: `const commits = d.before && d.before.sha !== sha ? [d.before, generated] : [generated];`

**Because (Jeff):** "not found" at the generated commit doesn't say whether the plan's
own work removed the quote or something later did. Tallow's Requirements quote is the
case: found at its base `3c59d26`, gone at its head `4d28b68`, still gone at `f02528f`.
Lanyard measures drift from where the work landed, and this makes that visible without
judging it. A plan with no as-built, or one whose head can't be resolved, keeps two
views.

**Three columns is wide (Claude, unanswered, so its fallback):** when the generated
view matches the head view exactly (same status, same lines), it collapses to one line,
"same as at `4d28b68`", with no code. That's a statement of fact, not a judgment. The base view
never collapses. As-built anchors already show head and generated, so the same
collapse applies to them.

## Decision: The home page orients a cold arrival, and every page links the profile visibly
- where: `src/render.ts`
- quote: `<p>Each symbol or file a plan points at has a page listing the plans there.</p>`

**Because (Jeff):** an agent arriving at the home page has to reverse-engineer what
it's looking at, and the profile link is only in `<head>`. One short paragraph says what
the site is and where to start (a file or a symbol, to find the plans that touch it),
and the header links the profile on every page.

## Decision: The dev server listens on localhost only
- where: `src/serve.ts`
- quote: `}).listen(args.port, () => {`

**Because (measured):** it listens on every interface (`*:4173`), so anyone on the
network can read the site. That's harmless for plans, but the edge will serve drafts,
and those are local by agreement.

## Decline: A `--base-url` flag for links that travel
**Because (Jeff and Claude):** agreed on how (absolute URLs in microdata, relative
links kept for `file://`), but it reopens gimlet's `itemtype` decline, and that deserves
its own look. This plan stays reviewable in one sitting.

## Decline: Cross-plan pages (open guesses, declines, sources)
**Because (Jeff and Claude):** they come after source and verdict exist. Source lands
here; verdict is the quince revisit.

## Guess: The commit that added a plan gives the order people mean
**Disproved if:** a plan whose adding commit is later was really decided earlier, and
the page's order misleads. Backfilled plans are where to look: pumice was backfilled
into its current file at `90c65b9`, a day after its work, though it still sorts first.

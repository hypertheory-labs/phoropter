# Show the evidence, not the whole symbol

Gimlet's site, read by aide's Claude through curl the way an agent would, showed all of
`MockPanel#` (144 lines) at both commits to support one selector quote. This round
makes a plan page carry only the evidence for each entry and moves the whole symbol
one link away. It also fixes a doubled title.

The cart ran on aide's cart rules, as play-acting (Jeff): aide's work is about to change
the cart's form, so phoropter records nothing about carts yet.

## Decision: A SCIP view shows the quote with a few lines of context, not the whole range
- where: `src/resolve.ts`
- quote: `view.hunks = [{ start: def.startLine, lines: body, marked }];`

**Because (aide's Claude, agreed by Jeff):** the whole range is a wall for a person and
a token cost for an agent, and the entry meant a few lines of it. The view still says
the range. Context is the same 3 lines as file anchors.

## Decision: When the quote isn't found, or there's none, the view shows the symbol's declaration
- where: `src/resolve.ts`
- quote: `view.hunks = [{ start: def.startLine, lines: body, marked }];`

**Because (Jeff):** showing nothing would make a missing quote look like a missing
symbol. For `MockPanel#` at `90c65b9` the declaration is the decorator, so the renamed
selector shows beside the base's old one. Claude's first fallback was no code at all.

## Decision: A view shows no code only when the symbol isn't in that commit's index
- where: `src/resolve.ts`
- quote: `` view.note = `symbol not in the index at ${commit.short}`; ``

**Because (Jeff and Claude):** then "no code" means one thing.

## Decision: The symbol page shows the whole range at the generated commit
- where: `src/render.ts`
- quote: `` ? `<dt>At ${esc(site.generated.short)}</dt><dd><code itemprop="file">${esc(def.file)}</code>, lines <span itemprop="startLine">${def.startLine}</span>–<span itemprop="endLine">${def.endLine}</span></dd>` ``

**Because (aide's Claude, agreed by Jeff):** the plan page carries the entry's evidence
and the symbol page carries the symbol. This is the first concrete case of Jeff's open
question, what is actually *in* the substrate.

## Decision: The home page's title is said once

- quote: `<title>${esc(stripMarkdown(title))} · ${esc(site.repoName)} at ${esc(site.generated.short)}</title>`

**Because (aide's Claude):** the layout appends the provenance, and the home page's
title already is the provenance. A plain bug.

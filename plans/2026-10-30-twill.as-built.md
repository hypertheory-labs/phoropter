## Chose: The guide is linked with `rel="help"`
- where: `src/render.ts`
- quote: `<link rel="help" href="${rel(here, 'guide/')}">`

**Because (Claude, not asked):** it's a registered relation that means what this link
is, so an agent finds the guide from any page without knowing phoropter's own names.
It's in every page's head and header, and on the orientation's link. The profile lists
it.

## Chose: The guide is read from phoropter's files, and says when they're uncommitted
- where: `src/guide.ts`
- quote: ``return dirty ? `commit ${sha}, with uncommitted changes to the guide` : `commit ${sha}`;``

**Because (Claude, not asked):** everything about the generated repository is read
through git at a commit, but the guide describes the tool, so it comes from whatever
phoropter is running. Reading it from git too would make an edited guide invisible
until committed, which is the wrong surprise while writing one. Saying "with
uncommitted changes" keeps the version line honest instead.

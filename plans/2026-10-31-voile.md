# Lines that show on any theme, plans in boxes, and a draft kept handy

Jeff, on Ghostty's default dark theme: "I'm not seeing some lines." Its background sits
near the 256-color grays the TUI used for rules, borders and the header bar, so they
vanish. The plan list is also hard to scan as two stacked lines a plan. And trying the
TUI needs a draft, which is deleted after every try. Written straight to `plans/`: each
is small, and Jeff said what he wanted.

## Decision: Rules, borders and the header bar use the theme's own colors
- where: `internal/tui/styles.go`
- quote: `rule:    lipgloss.NewStyle().Foreground(lipgloss.AdaptiveColor{Light: "250", Dark: "238"}),`

**Because (Jeff, then Claude):** a fixed gray is the same on every theme, and some
themes' backgrounds are close to it. Palette colors 0 to 15 are the theme's, and
themes set 8 ("bright black") to be readable as a quiet color. Rules, borders, the
gutter and empty layers use 8. The header bar is reverse video, which shows on any
theme.

## Decision: Each plan is a box, with a gap between them
- where: `internal/tui/screens.go`
- quote: `left = append(left, title, styles.dim.Render(ansi.Truncate("  "+meta(p), lw, "…")))`

**Because (Jeff):** "a box around each of the plans with a bit of a gap-y." A box holds
a plan's title and its dim line together, and the gap separates one plan from the
next. The chosen plan's border is the terminal's own text color, and the rest are
quiet. It costs room: five lines a plan, about six plans in a usual terminal. The list
scrolls.

## Decision: A sample draft is kept in `testdata/`, to copy in
- where (new): `testdata/sample.draft.md`

**Because (Jeff):** "maybe we should keep one handy for now." `cp
testdata/sample.draft.md plan.draft.md` puts it up, and deleting `plan.draft.md` and its
notes takes it down. It isn't named `plan.draft.md`, so it's committed and never
mistaken for a real draft. It has one prompt of each kind, an anchor that resolves, one
whose quote isn't there, a `where (new)`, and an entry with no anchor. Its anchors
drift as the code changes, which is something to see too.

# Landed plans aren't edited from the TUI

Jeff asked for a way to amend old plans from the TUI, meaning edit them literally, as a
test of the draft as a way to weigh an idea. The draft planned the feature properly,
said Claude's view up front (the wrong tool), and marked each place the feature
overturned earlier ground. Its one prompt defaulted to building it, because an agent
doesn't get a veto. Jeff answered in his own words at the second entry, and this plan
records that answer as a decline. What he wants instead, asking for a plan to be
revisited, is its own draft.

## Decline: Editing a landed plan from the TUI
- where: `internal/tui/screens.go`
- quote: `m.status = "only a draft takes notes; a plan is testimony"`

**Because (Jeff):** "If *anything* can be considered immutable, it has to be the plans -
so the tui should not allow you to edit them. It is a Ulysses mast move - I could always
edit them *outside* of this tool, but damn... that would be a bad idea." And: what was
wrong with "edit" was "I want to do this behind your back, Claude", not "let's have a
conversation around this." The draft found five collisions, any one of which would have
been a revisit:

- The TUI's own rule, which stays as it is: only a draft takes notes, and a plan is
  testimony.
- `next.md`: the TUI's one write is a draft's notes file, and it never writes the
  substrate. A landed plan is what the substrate is generated from.
- An edit lands in whatever commit comes next, and phoropter shows the new words under
  the plan's original date and `added` commit.
- A plan page carries no hash of its file, so the TUI couldn't check it was editing the
  version just read.
- The annotating agreement: whoever annotates a file doesn't edit it. Most plans here
  were written by Claude from drafts Jeff annotated, and batiste declined even
  converting a draft from the TUI.

Nothing on the site would show a plan had changed: phoropter reads plans as written,
and the TUI reads no git history. A reader, and an agent reading the page, would take
the edited words as what was decided. Changing a landed plan's ground stays what the
guide says it is: a revisit, in a new plan that cites the old one.

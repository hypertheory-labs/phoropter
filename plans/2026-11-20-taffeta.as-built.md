# As built: taffeta

Built as planned. `go test -count=1 ./...` passes, and `GOOS=windows go vet` does. A
test serves a repository, makes the next rebuild fail by making the site's parent
directory read-only, and commits. The home page, the guide and `lenses/` then carry the
`stale` item naming the new HEAD, while the header still names the commit served. A
reset back to that commit clears it, and so does a later commit that builds.

## Chose: The notice sits between the header and the page
- where: `internal/site/serve.go`
- quote: `page = strings.Replace(page, "</header>\n", "</header>\n"+staleNotice(h.stale, h.site), 1)`

**Because (Claude, not asked):** inside the header it would sit in the provenance item,
whose `commit` must stay the page's own. Just below it, it's the first thing read
after the commit it qualifies, by a person or by an agent reading top to bottom. It's
styled like a highlighted quote, with a rule in the missing-anchor color.

## Chose: A forced rebuild that fails at the served commit says so too
- where: `internal/site/serve.go`
- quote: `if sha == l.site.Generated.SHA && !force {`

**Because (Claude, not asked):** `r` rebuilds even when HEAD hasn't moved, say after
installing an indexer. If that fails, the page says HEAD couldn't be built, though the
site served is from that same commit, built earlier. It reads oddly, but it's true: the
last attempt failed, and the reason is worth showing.

# What Jeff's first answers showed

Jeff tried batiste (answering from the TUI) on a throwaway draft and left three notes.
His Select answer was recorded right in the notes file, but the TUI showed it as all
four options with nothing marking his two. Its note, on phoropter's page, ran into the
last option. And a form closed with `esc` loses what was typed without asking. Written
straight to `plans/`: each fix is small, and Jeff's notes already say what's wanted.

## Decision: A Select's answer shows which options were chosen
- where: `internal/substrate/model.go`
- quote: `Answer:   prose(v.Get("answer")),`

**Because (Jeff):** "see what it records as my selections?" Phoropter renders the
answer's `- [x]` list as disabled checkboxes, so the choice is only in each `<input>`'s
`checked`, which the profile doesn't define, and the TUI read the answer as text
without it. The TUI reads the checkboxes as `[x]` and `[ ]`, and notes the gap
(`answer-choices-unprofiled`). The brief asks phoropter for the chosen options as
properties.

## Decision: A Select's note is written after a blank line
- where: `internal/tui/form.go`
- quote: `out = append(out, "**Note:** "+note)`

**Because (Claude, measured):** the agreement's own example puts `**Note:**` directly
under the list, where markdown makes it part of the last item. On phoropter's page,
Jeff's note read as part of "no-quote". A blank line keeps the list and the note apart,
and every reader of the notes file sees the same entry. It's a departure from the
example, not from the rule, so `docs/annotating.md` shows it and says why.

## Decision: `esc` asks before throwing away what's typed
- where: `internal/tui/form.go`
- quote: `case "esc":`

**Because (Jeff):** "if we escape out of these without saving, might need an 'are you
sure'". When the form has anything in it, the first `esc` says so, and a second `esc`
discards. Any other key carries on. An empty form still closes at once.

## Guess: Answers written by the TUI read back the same in the TUI and on the page
**Disproved if:** after these fixes, an answer the TUI writes shows differently in the
TUI than on phoropter's draft page: a choice missing, or a note in the wrong place.

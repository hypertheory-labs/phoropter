# `init`'s first plan knows a new repository from one with history

Muslin, which made `init` write a repository's first plan, wrote the same one for every
repository, and the trial (`shelf/trial.md`) ran it in a new one: a README and a single
commit. Two things moved. The template's "Looking back" entry said "the code here was
written before these plans", which wasn't true there. The agent said so in
conversation, then converted the default as written, which is what a default invites.
And the trial's first real work was setup: the TypeScript indexer needed a
`package.json` and a `tsconfig` before a symbol could be anchored, and Jeff's reaction
was that a new repository's first plan should be how it builds. A third, smaller thing:
the pointer `init` prints is indented for the terminal, and pasted into AGENTS.md as it
was, its paragraph became a Markdown code block.

## Decision: `init` tells a new repository from one with history, and says which it saw
- where: `init.go`
- quote: `func writeFirstDraft(root, base string) error {`

**Because (the trial, then Claude):** muslin's template assumed code that predates the
plans. `init` already reads the repository, so it can see which kind this is and fill
the template to match, the way it fills `{{base}}`. The walkthrough says what it saw
("a new repository: N commits, M files"), so a wrong guess is visible and the person
can annotate it away. "New" is fewer than 5 commits and no more than 10 tracked files,
not counting README, LICENSE, `.gitignore` and the agent's instructions file (Claude's
fallback, which Jeff kept). The trial's repository had 1 commit and 1 file. Anything
bigger has history worth asking about, and the existing entry fits it.

## Decision: In a new repository, "Looking back" says there's nothing to look back on yet
- where: `init.md`
- quote: `**Because (phoropter's default):** the code here was written before these plans. When new`

**Because (the trial):** the entry stays, since a new repository grows code soon, and
some of it (generated scaffolding, a copied starter) arrives without a plan. Its reason
changes: nearly everything here will be born under a plan, and when work touches code
that arrived without one, such as a scaffold or a vendored file, the agent offers the
same archaeology. True on day one, and still true later.

## Decision: In a new repository, the first plan suggests the next one: how it builds
- where: `init.md`
- quote: `### Question: What's too small for a plan here?`

**Because (Jeff, on the trial):** "maybe 'and your first plan should be how to get your
build and packages set up'". The trial's setup happened in pieces, inside a pipeline
test, because nothing said it was a decision. One sentence in the template's opening,
only for a new repository: the first plan after this one is usually how the project
builds, its packages, and what an indexer needs to read it. The agent doesn't offer to
draft it once this plan converts (Claude, and Jeff agreed): an offer right then is the
agent setting the agenda. The person starts the work they came for, and the build plan
is there to reach for.

## Decision: The pointer prints flush left, between rules
- where: `init.go`
- quote: `b.WriteString(strings.TrimRight("     "+line, " ") + "\n")`

**Because (the trial):** indented five spaces for the terminal, it pasted as a code
block. Flush left between two `----` lines reads as clearly in a terminal and pastes as
the Markdown it is.

## Decline: Two templates
**Because (Claude, not asked):** a second `init-new.md` would drift from the first; the
entries are the same twelve, and only two of them read differently. One template with
two variant passages keeps them in step.

## Decline: Asking the person which kind of repository this is
**Because (Claude, then Jeff):** `init` can see it, and a question nobody needs to
answer is noise on the first screen. The walkthrough saying what it saw is the
correction path. Jeff added why it barely matters: the first plan isn't configuration,
it's hints for starting in this way of working, and a hint that doesn't fit gets
trimmed later, not rebuilt.

## Guess: Nobody on a new repository annotates "Looking back" as wrong
**Disproved if:** the next fresh repository's first plan converts with a note or a
conversation saying the entry doesn't fit.

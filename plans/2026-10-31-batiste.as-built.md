## Chose: A restated prompt uses the draft's own heading text, not the page's
- where: `internal/notes/notes.go`
- quote: `func (s *Source) Prompt(kind, text string) (Heading, bool) {`

**Because (Claude, not asked):** phoropter matches an answer to its prompt by exact text,
and the page renders inline markdown, so a prompt with backticks reads differently there.
The TUI finds the prompt in `plan.draft.md` by its text with inline markdown set aside,
then restates the heading as the source writes it.

## Chose: The warning is a line in the form, while no notes file exists
- where: `internal/tui/form.go`
- quote: `This creates plan.draft.notes.md, which fixes the draft until it converts or the notes are deleted.`

**Because (Claude, not asked):** the plan said once, before the first write. Tying it to
whether the notes file exists says it exactly as often as it's true, including after a
conversion deletes the notes and a new draft starts.

## Chose: `s` skips at once, with no form
- where: `internal/tui/screens.go`
- quote: `return m.write(s, newPromptForm(r.prompt, false), true)`

**Because (Claude, not asked):** a skip has nothing to fill in, and answering again
replaces it, so a mistaken skip costs one more keystroke.

## Chose: The text box only types at its end
- where: `internal/tui/form.go`
- quote: `case tea.KeyRunes, tea.KeySpace:`

**Because (Claude, not asked):** a full editor inside the TUI would duplicate `$EDITOR`,
which `ctrl+e` already opens with what's typed so far. Typing, backspace and newlines
cover a short answer.
